# 윗급 모델 비교 (지시문 v6, 같은 일 두 후보 문제)

2026-11-20 · 지시문 `prompt-v6.md` 고정 · 모델만 바꿔 같은 세트로 돌림

## 1. 계기

v6 배포 뒤 사용자가 "같은 일이 두 후보로 나오면 후보가 늘고, 그러면 믿음이 떨어져 안 쓰게 된다"고 했다. 지시문 문제인지 모델 문제인지 가리려고 다른 모델을 같은 지시문으로 돌렸다. 사용자 결정 순서는 이렇다.

1. 윗급 모델 비교(② 이 문서)를 먼저 한다.
2. 윗급 모델도 같은 일을 둘로 나누면 코드로 합치기(①)를 한다.

대상은 다음 네 모델이다.
- gpt-6.1-terra, claude-sonnet-5-5: 사용자가 처음 고름. "6.0 테라"는 없는 모델이라 빠졌다.
- gpt-6-sol: 소넷과 같은 값대.
- claude-haiku-5-5: luna와 같은 값대. 10월 첫 비교(DEC-19) 때는 지시문 v1이었다.

**같은 일 두 후보 내역**

| 모델 | 둘로 나온 일 |
|---|---|
| luna | H05 "테스트 다시 돌리기" + "다시 돌려 달라고 알리기"(두 번 다) |
| Haiku | H08 "오픈 당일 모니터링하기"를 맡은 두 사람 각각으로 나눔. 경계: H01 "개발 일정과 공수 다시 보기"는 박지훈 님 공수 재산정과 겹친다 |
| 테라 | H01 요건서 "작성"과 "범위 잡기", H02 면담 "일정 조율"과 "면담하기", H06 배너 "이미지 요청"과 "문구 작성" |
| sol | H01 요건서 "마련"과 "범위 정하기", H02 면담 "일정 조율"과 "면담 끝내기", H08 모니터링(확인 필요 + 김하늘) |
| 소넷 | 없음. 1회째 경계: H01 "개발 일정 다시 확인하기"(일정과 공수라 내용이 조금 다름). 2회째는 이것도 없음 |

- H01 '개발 일정'과 '고객 안내 문구'(근거 [3] 같음)는 같은 일이 아니다. 한 문장에서 서로 다른 일 둘을 말한 경우다. `score.mjs`의 '같은 일 의심'은 근거 겹침·같은 담당만 보므로 이런 쌍도 잡는다. 그래서 위 표는 사람이 확인한 수다.

## 3. 해석

- **같은 일 두 후보는 모델 영향이 크다.**
  - 지시문이 같아도 테라·sol은 3쌍, luna·Haiku는 1쌍, 소넷은 두 번 다 0쌍이었다.
  - 테라·sol은 더 꼼꼼히 쪼개는 쪽이다. 값은 비싸도 이 문제에는 오히려 나쁘다.
  - 소넷은 후보 수가 luna와 비슷하면서 놓친 것이 가장 적고, 두 번 결과도 거의 같았다.
- **비용(소넷)**
  - 같은 토큰 수 기준으로 luna보다 20배 비싸다(입력 2·출력 10달러/100만 토큰).
  - 한국어 글이 토큰으로 약 1.9배 많게 세어진다(보류 입력 9.2만 대 4.9만). 그래서 실제로는 약 27배다.
  - 11월 사용량은 20일까지 14회이고, 평균 입력 1.4만·출력 3.2천 토큰(OpenAI 기준)이다. 이대로면 한 달 약 20~25회라 월 약 2.5천 원이다(4절에서 다시 셈). 예산 대기선(월 2.4만 원, DEC-19)보다 낮다.
- **Haiku 5.5는 싼 쪽의 대안이다.** luna의 약 2배 값으로 놓친 것은 소넷만큼 적다. 다만 같은 일 두 후보는 luna와 비슷하게 1쌍이 남는다.
- **소넷으로 바꾸려면 서버를 고쳐야 한다.**
  - 처리 함수(`process-record`)는 지금 OpenAI만 부른다. Anthropic 호출(`output_config.format`), Supabase 비밀값 `ANTHROPIC_API_KEY`(사용자가 넣음), 비용 기록 단가를 넣어야 한다.
  - 거절(`refusal`)이 오면 luna로 다시 부르는 대비도 넣어야 한다.
  - 모델 선택(DEC-19, 저가 LLM 우선)을 바꾸는 일이라 사용자 결정이 필요하다. 회의 글을 받는 회사도 OpenAI에서 Anthropic으로 바뀐다.

## 4. 결정(DEC-113, 2026-11-20 사용자)

- 할 일·결정 후보 뽑기만 소넷 5.5로 바꾼다. 소넷이 같은 일을 나누지 않았으므로 ①(코드로 합치기)은 하지 않는다.
- 나머지 단계는 luna 그대로다.
  - 용어 교정, 기존 할 일 비교, 프로젝트 연결, 현재 상태, 회의록 문서, 업무계획 다듬기, 비서
  - 받아쓰기(gpt-transcribe)
- 비용은 다시 셌다.
  - 11월 실제 추출 14건은 평균 입력 약 1.45만·출력 약 3.2천 토큰(OpenAI 기준)이고, luna로 건당 약 4원이었다.
  - 소넷으로는 건당 약 110~125원이다. 11/18 회의는 평균보다 짧아 67원이었다.
  - 이대로면 월 약 2.5천 원이다. 실제 회의 9건 평균(약 142원, 긴 회의가 많음)으로 치면 월 약 3천 원이다.
  - 같은 달 나머지 AI 비용(연결·상태·문서·계획 등)은 약 470원이고 그대로다.
- 처리 함수(`process-record/claude.ts`)는 다음과 같이 동작한다.
  - 한 번의 호출(무료 플랜 150초 제한)에서 소넷에 약 115초를 준다. 2시간 회의가 약 105초였다.
  - 거절·몰림(429)·서버 문제(5xx·529)·길이 초과·시간 초과면 luna로 한 번 더 부른다.
  - 이 호출에 luna를 부를 시간(60초)이 남지 않았으면 '소넷이 시간 안에 답하지 않아 luna로 다시 정리해요'로 멈춘다. 앱이 3초 뒤 다시 부를 때 luna로 뽑는다.
  - 시간이 빠듯하면 프로젝트 연결 제안은 앱이 켜질 때 만든다.
  - Anthropic 키·크레딧 문제는 'Anthropic API 키…' 글로 기다린다.
  - `ANTHROPIC_API_KEY`가 없으면 luna로 뽑는다.

## 5. 시험 도구 바뀐 것

- `eval/llm/prices.json`: 모델별 단가. `run.mjs`·`run-record.ts`가 같이 읽는다. 테라·sol 단가는 가격 정리 글 기준이고, 소넷·Haiku 5.5는 Claude API 안내 표와 같다.
- Claude 호출을 도구 강제 호출(`tool_choice: tool`)에서 응답 형식 지정(`output_config.format` JSON 스키마)으로 바꿨다. Sonnet 5.5는 도구 강제 호출을 400으로 막는다. 거절·길이 초과(`stop_reason`이 `end_turn`이 아님)는 실패로 센다. 10월 Haiku 결과는 도구 강제 호출로 얻은 것이다.
- `run-record.ts`: 4번째 인자로 모델을 고른다(빼면 gpt-6-luna).
- `score.mjs`: '같은 일 의심 N쌍'을 낸다(근거 겹침·같은 담당). 검토표에도 줄을 넣는다. 서로 다른 일도 잡히고 담당이 다르게 나뉜 쌍(H08)은 못 잡으므로 사람이 확인한다.

비용: 테라 약 320원, 소넷 약 1,720원(보류 2회 1,232·보안 198·실제 회의 2번 134·결정 85·화자 74), sol 약 630원, Haiku 약 80원. 합계 약 2,750원. 처음 소넷 실행은 도구 강제 호출 400으로 전부 실패해 0원이었다.
