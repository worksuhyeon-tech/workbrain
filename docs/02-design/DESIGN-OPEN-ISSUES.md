> **Codex 교차 검토 완료(2026-10-17)**: 원본 브리프를 직접 대조했다. **Q0 점검은 완료했으나 누락/과소 명세 M10~M12는 미해결**이다. 전체 대조표·추가 발견·종결 조건은 아래 **G절**을 따른다. DEC-15~20과 Q1/Q2/Q4/Q6/Q7의 사용자 확정은 유지한다. 기존 A~F의 이전 공급자 전제와 미체크 박스를 현재 미결정으로 해석하지 않는다(C10). 제품 설계 승인이나 구현 검증 완료를 뜻하지 않는다.

> 이 문서는 Plan에서 발견한 **기술적 모순 / 요구사항 누락 / UX 문제**와, Design 확정 전 반드시 해소해야 할 **미확정 항목**을 분리해 모은 것이다. Plan 문서는 수정하지 않았다. Codex가 G1~G6 근거 확인과 사용자 결정을 거쳐 이 항목들을 닫으면 Design을 v0.2로 확정한다.
>
> **Design 작업의 전제(투명성)**: 이 Design은 Codex가 저장소에 push한 Plan v0.2 문서 집합(PRD·아키텍처·데이터·UX·로드맵·위험·추적표·검토)만을 근거로 작성했다. Codex 세션에만 있던 원본 사용자 브리프 원문은 Claude Code가 보지 못했다. 따라서 **FR-01~27 외에 원본 브리프에 있었으나 Plan에 미반영된 요구사항이 있는지**는 Codex가 교차 확인해야 한다(→ Q0).

## D. 게이트별 검증 체크리스트 (Codex 수행)

### G1/G2 조사 결과 (2026-10-17, Claude Code)

**G1 — bkend**
- `bkend.ai`·`www`·`docs`·`console`·`api` 하위 도메인 모두 **DNS 조회 실패**(로컬 DNS와 8.8.8.8 모두 주소 없음). 같은 환경에서 다른 사이트는 정상 접속. 2026-10-16의 502와 달리 이번에는 도메인 자체가 응답하지 않는다. 서비스 종료라고 단정하지는 않는다(사용자 브라우저·계정으로 확인 필요).
- 확인된 2차 자료(공식 안내 페이지, 2025-12-09 수정): 베타 무료·SLA 없음·API 사양 예고 없이 변경 가능, 리전 AWS 서울만, **데이터 내보내기 베타 미지원**, 백업/복원 언급 없음, 정식 출시 목표 2026 Q1. [bkend 안내(slashpage)](https://slashpage.com/bkend/943zqpmqxrxpd2wnvy87)
- 판단: 접속 불가 + 내보내기 미지원 + SLA 없음이면 G1의 "내보내기/복원·가격" 조건을 충족할 근거가 없다. **사용자 확인 후 Q1(대체 백엔드) 결정 필요.**
- 대안 참고: Supabase Free는 DB 500MB·파일 1GB·**백업 없음·1주 미사용 시 일시정지**, Pro는 월 $25부터(약 37,500원으로 단독으로 월 목표 초과). [Supabase 가격](https://supabase.com/pricing)

**G2 — 모델·비용**

### G.7 이번 검토의 완료와 후속 조건

- **완료:** 원본 브리프 §0~10 직접 대조, FR-01~30/NFR-01~09와 단계 배치 검토, 발견 사항·근거·수정안·TC 연결 기록. Q0 점검 완료를 todo에 기록한다.
- **남음:** M10~M12의 PRD/추적표/설계/시험 기준 반영, 높은 우선순위 설계 결손 해소, Q8~Q10 답변, 기존 미해결 M/U 및 G1~G6의 해당 단계 검증. 이번 제안의 기록만으로 문제를 종결 처리하지 않는다.
- **다음 행동:** 보완 설계에서 각 항목의 반영 절·검증 기준을 연결한 뒤 Q5 사용자 승인을 받는다. Q5 이전에 Design 승인 상태를 올리거나 P0/Do로 전환하지 않는다.
- `.pdca-status.json`은 `phase=plan`, `designApproved=false`, `matchRate=null`을 유지했다. bkit 상태 도구는 세션 미초기화 오류였으므로 문서를 기준으로 확인했다. 자동 수준 감지는 Starter를 반환했으나 공통 지침에 따라 프로젝트 수준 **Dynamic**을 유지했다.
- 검증은 문서·목업 소스·공식 권한/SMTP 문서의 교차 검토다. 실제 DB·모델·메일·녹음 시험은 수행하지 않았다. 단가·공급자 한도·정책의 전체 재조사는 이번 결과에 포함하지 않는다.

### G.8 Claude 반영 결과 (2026-10-17, Design v0.1.4)

- G절의 M10~M21, C7~C10, U6~U7은 위 표의 각 항목에 반영 위치를 적었다. Q8~Q10은 사용자 답변으로 **DEC-21**에 기록했다.
- 범위 변경은 없다(새 FR 번호 없음). 기존 FR-02/06/07/15/17/22·NFR-06의 인수 조건과 TC-01/02/05/06/08/10/11/12/14/15/23/24/25에 보완 사례를 추가했다.
- DDL은 테이블 정의 순서상 앞에서 뒤 테이블을 참조하는 FK가 있다(예: `resource → source_record`). 구현 시 마이그레이션에서 생성 순서를 정렬하거나 FK를 후처리로 추가한다.
- 아직 **실측은 하지 않았다**. RLS 격리·동시 승인·백업 복원·저장 암호화 설정·메일 결과 불명 처리·한국어 품질은 P0/P1 시험으로 확인한다. 이 반영으로 문제를 '검증 완료'로 표시하지 않는다.
