## 5. 근거 자료와 접근 한계

사용자 원본 브리프 및 대화에서 확정한 선택을 제품 요구사항의 근거로 사용했다. 개인정보가 포함된 브리프 원문은 공개 저장소에 복사하지 않았다.

2026-10-16에 확인한 자료:

- [bkend 홈페이지](https://bkend.ai), [문서 후보](https://docs.bkend.ai), [요금 후보](https://bkend.ai/pricing): 이 실행 환경에서 502 또는 접근 불가. 문서/요금 경로의 현행 유효성도 미확인이다. 서비스 자체 장애라고 단정하지 않는다.
- 설치된 dynamic 스킬: bkend 기능 설명과 예제 참고용. 공급자 공식 계약·가격 근거 아님.
- [OpenAI 가격](https://developers.openai.com/api/docs/pricing): STT 예상 단가 확인.
- [GPT-4.1 Mini](https://developers.openai.com/api/docs/models/gpt-4.1-mini), [GPT-5 Mini](https://developers.openai.com/api/docs/models/gpt-5-mini): Deprecated 표시 확인, 확정 신규 모델로 선택하지 않음.
- [Cloud Run 가격](https://cloud.google.com/run/pricing), [GCS 가격](https://cloud.google.com/storage/pricing): 계산식·과금 항목 참고, 지역별 견적 확정 아님.
- [Supabase 가격](https://supabase.com/pricing): 대안 비교에만 사용.
