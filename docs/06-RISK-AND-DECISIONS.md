## 3. 게이트와 결정 책임

| 게이트 | 시점 | 담당 관점 | 필요한 증거 | 실패 시 행동 |
|---|---|---|---|---|
| G1 bkend 적합성 | Design 상세 설계 전 | 아키텍트/보안 | 공식 요금·리전·소유자 격리·토큰 철회·고유성/조건부 쓰기·내보내기/복원·보관 문서, 검증 계획 | bkend 종속 확정 중지. 범위/예산 조정 또는 Supabase 예외를 사용자 결정으로 기록 |
| G2 비용·모델 | Design 상세 설계 전 문서 확인, P0 실측 | PM/기술 | 활성 모델·가격·처리 조건, 10/20/30시간 계산, 토큰·시간 표본 | 자동 상향 결제 금지. 처리량·모델·예산 재결정 |
| G3 녹음·파일 | P0 | Android/QA | 실제 기종·OS, 60분 시험·중단 손실·공유 가능한 파일 | 녹음 범위/복구 안내 개정 |
| G4 외부 AI | P3 시작 전 | 보안/API | 클라이언트별 인증·철회·읽기 범위·데이터 전송 고지 | 지원 클라이언트 범위 조정 |
| G5 회사 자료/메일 | 회사 자료 또는 회사 메일 사용 전 | 사용자/회사 담당 | 외부 저장·AI 처리·발송에 대한 허용 범위 | 샘플·개인 자료 유지 |
| G6 의미 검색 | P2 시작 전 | 데이터/아키텍트 | bkend 검색 지원 또는 독립 색인 후보, 격리·삭제·비용 | 후보 비교 후 별도 Plan, pgvector 자동 추가 금지 |

Plan 문서 개정 완료와 Design 승인 가능 상태는 다르다. G1/G2의 미확인 사실을 기록한 상태로 v0.2 문서를 전달하되, 이를 검증 완료로 표시하지 않는다. 나머지 게이트의 실측은 해당 단계의 진입/종료 조건이다.

## 5. 근거 자료와 접근 한계

사용자 원본 브리프 및 대화에서 확정한 선택을 제품 요구사항의 근거로 사용했다. 개인정보가 포함된 브리프 원문은 공개 저장소에 복사하지 않았다.

2026-10-16에 확인한 자료:

- [bkend 홈페이지](https://bkend.ai), [문서 후보](https://docs.bkend.ai), [요금 후보](https://bkend.ai/pricing): 이 실행 환경에서 502 또는 접근 불가. 문서/요금 경로의 현행 유효성도 미확인이다. 서비스 자체 장애라고 단정하지 않는다.
- 설치된 dynamic 스킬: bkend 기능 설명과 예제 참고용. 공급자 공식 계약·가격 근거 아님.
- [OpenAI 가격](https://developers.openai.com/api/docs/pricing): STT 예상 단가 확인.
- [GPT-4.1 Mini](https://developers.openai.com/api/docs/models/gpt-4.1-mini), [GPT-5 Mini](https://developers.openai.com/api/docs/models/gpt-5-mini): Deprecated 표시 확인, 확정 신규 모델로 선택하지 않음.
- [Cloud Run 가격](https://cloud.google.com/run/pricing), [GCS 가격](https://cloud.google.com/storage/pricing): 계산식·과금 항목 참고, 지역별 견적 확정 아님.
- [Supabase 가격](https://supabase.com/pricing): 대안 비교에만 사용.
- [Android 통화 음원 권한](https://developer.android.com/reference/android/media/MediaRecorder.AudioSource): 일반 앱의 통화 직접 캡처 제약.
- [Android 파일 선택](https://developer.android.com/training/data-storage/shared/documents-files): 사용자 선택 파일 접근.
- [Android 적응형 UI](https://developer.android.com/develop/ui/compose/layouts/adaptive/get-started-with-adaptive-apps): 창 크기 기반 화면 전략.
- [Google Calendar 동기화](https://developers.google.com/workspace/calendar/api/guides/sync): 후속 연동의 증분/전체 재동기화 검토 근거.
- [TickTick 기능](https://ticktick.com/features): 기능 벤치마크 범위, 자산 복제 없음.

## 6. 다음 사용자 결정

현재 사용자가 이미 선택한 범위·예산·승인 방식을 다시 묻지 않는다. 남은 결정은 G1/G2의 근거 확인 후 **bkend 기준안 유지 가능 여부**, 필요 시 **백엔드 예외 또는 처리량/예산 조정**, 그리고 **Design 진입 승인**이다. 외부 자원 생성 승인은 별도로 다룬다.
